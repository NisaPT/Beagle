    Os amigos veem só a alcunha, as estrelas e o nível da quinta (nunca fotografias nem mensagens). Os dados vêm da cloud: para aparecerem, a conta dos pais tem de estar ligada nos dois aparelhos, com a versão mais recente do jogo.

    Voz

    Prioridade a vozes neurais online PT-PT (masculina e feminina). Configure aqui o endereço do gateway TTS do projeto. O gateway deve guardar as credenciais do fornecedor no servidor e devolver áudio; nunca coloque chaves API neste campo nem no JavaScript público. Sem gateway configurado, é usada a voz PT-PT do dispositivo, quando disponível.

    —

    Privacidade e segurança

    O progresso, os perfis e as estatísticas ficam guardados localmente neste dispositivo. Não existe conta na nuvem nem sincronização entre aparelhos nesta versão. Não introduza dados sensíveis da criança.

    Os dados podem ser apagados por perfil através do botão acima. Para apagar todos os dados locais da aplicação, limpe o armazenamento do site nas definições do navegador.

    As vozes neurais online requerem um serviço TTS com backend seguro e credenciais protegidas. A aplicação não inclui chaves de fornecedor nem envia dados pessoais para terceiros.
